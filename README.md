# The Archaeologist's Notebook: Excavation Guide & Byzantine Architecture (2009)

An interactive, dual-mode educational application developed as part of a national cultural heritage project. 

### 🏛️ Project Background
This application was created for the project **"Implementation of fifteen (15) interactive multimedia publications for the most important museums and archaeological sites in Greece"** for the **Hellenic Ministry of Culture**. 
* **Production Company:** Hypermedia Ltd. (Cyprus)
* **Role:** Instructional Designer

### 🎯 My Contribution
* **Content & Structure:** Organised and archived scientific content, and designed the educational modules.
* **Creative Development:** Developed the interactive scenarios, created the storyboards, and authored all copywriting.

### ⚙️ Technical Note & Emulation
Originally built in Adobe Flash (SWF format). It is preserved and rendered here using the Ruffle emulator to ensure modern web compatibility.
